# 🐾 Звероград — математические приключения для 2 класса

Интерактивная обучающая игра на русском языке по тематике учебника и трёх частей рабочих тетрадей Л. Г. Петерсон, а также тренажёра таблицы умножения. Игровые сюжеты и примеры созданы специально для этого проекта.

## 🎮 Что внутри

- **Часть 1 — Лес любознательных:** цепочки, сложение и вычитание, единицы измерения, уравнения, трёхзначные числа.
- **Часть 2 — Город мастеров:** периметр, фигуры, скобки, площадь, рисование по клеточкам, умножение и деление.
- **Часть 3 — Остров чемпионов:** таблица умножения, деление с остатком, уравнения, работа с трёхзначными числами, объём и задачи на логику.
- **32 игровых уровня**, каждый запуск генерирует 10 новых заданий.
- Магазин, 16 коллекционных зверей, предметы для парка и анимированные прогулки.
- Мини-игра «Поймай беглеца», скоростные математические раунды, достижения и награды.
- Подсказки, объяснения ответов, монеты и звёзды.
- Адаптивная вёрстка для телефона, планшета и компьютера.
- Сохранение прогресса в `localStorage` браузера, без сервера и регистрации.

## 🚀 Как запустить

Откройте [сайт игры](https://07kir09.github.io/math_2_class/) **после включения GitHub Pages** или скачайте `index.html` и откройте его в любом современном браузере. Для игры не нужны сервер, сборка или внешние зависимости.

### Включение GitHub Pages

Откройте **Settings → Pages → Build and deployment → Source: Deploy from a branch**. Укажите **Branch: main**, **Folder: / (root)** и сохраните изменения. GitHub разместит сайт по адресу:
`https://07kir09.github.io/math_2_class/`

## 🧑‍🏫 Для взрослых

Разделы можно проходить в любом порядке. За 6 из 10 правильных ответов уровень считается освоенным. При неправильном ответе ребёнок получает объяснение, а подсказки бесплатны. Задания генерируются заново, поэтому можно тренировать тему несколько раз.

## 🔒 Данные

Данные о покупках, монетках и прогрессе сохраняются **только в браузере на текущем устройстве**. Удаление данных браузера сбросит сохранение. Данные не передаются на сервер.

## 🛠️ Технологии

HTML + CSS + Vanilla JavaScript. Без зависимостей, сборки и бэкенда.
